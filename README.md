# 错题诊断器

不是又一个错题本，而是一台"错因诊断 + 效果验证"的机器。

## 一句话
给高一学生在周测后整理错题时用，解决"知道错了但不知道错在哪一类、
下次同类题照样错"的问题。

## 目标用户
先是我自己，再是同班同学。
